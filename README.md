#  Конвертер единиц измерения

Простое, красивое и быстрое веб-приложение для конвертации физических величин: **длина**, **масса**, **объем** и **температура**.  
Работает в реальном времени, поддерживает переключение единиц и удобную кнопку Swap (обмен значений).

##  Возможности

-  **Мгновенная конвертация** — результат обновляется при вводе или смене единицы.
-  **4 категории величин**:
  - Длина (метры, километры, мили, футы, дюймы, ярды и др.)
  - Масса (килограммы, граммы, фунты, унции, тонны)
  - Объем (литры, миллилитры, галлоны, кубические метры, чашки)
  - Температура (Цельсий, Фаренгейт, Кельвин)
-  **Кнопка Swap** — меняет местами исходную и целевую единицы с переносом значения.
-  **Адаптивный дизайн** — корректно отображается на ПК, планшетах и смартфонах.
-  **Высокая точность** — до 6–8 знаков после запятой, с экспоненциальной записью для малых чисел.
-  **Чистый код** — без внешних зависимостей, один HTML-файл.

##  Установка и запуск

### Локальный запуск

1. Скачайте файл `converter.html` (или сохраните код из репозитория).
2. Дважды кликните по файлу — он откроется в вашем браузере по умолчанию.
3. Готово! Никаких серверов и зависимостей не требуется.
